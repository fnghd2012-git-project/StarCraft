# 포인터 인자 p_ 규칙 적용

요청: 포인터를 넘겨받는 부분을 이름으로 구분할 수 있도록 `p_`를 붙인다.

## 적용

- raw pointer와 `shared_ptr`/`unique_ptr`를 받는 함수 매개변수에 적용했다. 예: `p_channel`, `p_session`, `p_operation`, `p_connection`.
- 함수 선언·정의 39곳, 직접 작성한 소스·헤더 14개. 같은 함수의 선언과 정의를 각각 센 값이다.
- 일반 참조, 값 인자, 지역·멤버 변수는 기존 규칙을 유지한다. `stPlayer& player`를 포인터로 바꾸지 않는다.
- 기존과 새 코드를 토큰으로 대조했다. 새 인자의 `p_`를 제외하면 실행 코드가 동일하다. 주석과 공백은 비교에서 제외했다.
- CM_/SM_/SS_/SYS_와 번호, 타입·소유권·패킷 형식을 유지한다.
