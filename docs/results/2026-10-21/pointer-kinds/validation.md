# 포인터 종류별 명명 적용 검증

2026-10-21 현재 작업 트리 기준. 커밋·푸시는 수행하지 않았다.

## 변경 범위

- 소스·헤더 31개: raw `p_`, shared `sp_`, unique `up_`. 멤버는 `m_up_redis`, `m_sp_latest`처럼 조합한다.
- `weak_ptr` 사용처는 없으므로 `wp_`는 향후 사용 규칙만 등록했다.
- 매개변수·지역 변수·구조체 필드에 적용했다. 일반 참조·값·포인터 컨테이너는 기존 이름을 유지한다.
- 자료형·수명·소유권·게임 동작·CM_/SM_/SS_/SYS_ 번호와 Protobuf 본문은 변경하지 않았다.
- 변경 전 스냅샷과 비교해 주석·공백·접두사를 제외한 코드 토큰과 리터럴이 동일함을 확인했다. `rename-audit.json` 참조.
- 첫 빌드에서 발견한 구조체 내부의 이전 멤버명 참조 세 곳을 수정한 뒤 전체 빌드를 다시 확인했다. 최초 로그도 보존했다.

## 실행 검증

| 항목 | 결과 |
|---|---|
| x64 Debug/Release 전체 빌드·self-check | 통과 |
| IOCP/WSAPoll 통신 | 단편 헤더·본문, 병합 패킷, 잘못된 패킷 거부, 동시 접속 통과 |
| 게임 흐름 | 로그인·서버 이동·일반/월드 채팅·이동·공격·사망·복귀·승패·재시작 통과 |
| 계정·스킬 | 비밀번호·계정 유닛 저장·스킬별 결과 검증 통과 |
| 자동 전투 | A/B/C 자동 입장·적 건물 파괴·승리·원래 서버 복귀, 비공격 유닛 대기 통과 |
| Redis 랭킹 | 장애/복구, 최종 SQL 트랜잭션·재시도 중복 방지 통과 |
| 리플레이 | 실제 상태 일치, 손상·잘림 검출, 오프라인 재생 제어 통과 |

`regression.json`에 종료 코드·소요 시간, 같은 폴더의 로그에 각 확인 결과를 보관했다. 빌드 산출물 해시는 `binary-hashes.json`을 참조한다. 이번 작업은 명명 변경이므로 과거 부하 측정 수치를 새 결과로 표시하지 않았다.

## 문서 검증

- 학습 PDF 5개 및 기본 테마 A의 포트폴리오·경력기술서 2개를 갱신했다.
- 종류별 명명 표, 실제 코드 발췌, 도식 변수명, 함수 줄 번호를 현재 소스와 맞췄다.
- 총 192쪽 렌더링·텍스트·페이지 경계 검사 통과. 이전 검토본과 비교해 바뀐 51쪽 및 주요 코드·컨벤션 페이지를 시각 확인했다.
- `pdf-validation.json`에 최종 파일 해시와 검증 결과를 기록했다.
- 이전 PDF와 외부 원본은 archive에 보존한다. 외부 반영 경로·백업·최종 해시는 `publication.json`을 참조한다.
