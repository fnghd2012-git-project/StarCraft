# 2026-10-21 코드 컨벤션 정리 검증

사용자 요청: 클래스 C, 구조체 st, 클래스 멤버 m_, 전역 g_ 규칙과 익숙한 변수명을 적용하고 코드·PDF·A 경력기술서를 함께 수정한다. CM_/SM_/SS_/SYS_는 유지한다.

## 변경 범위

- 직접 작성한 C++ 소스·헤더 71개를 현재 작업 사본 기준으로 정리했다. 자동 생성 Protobuf 및 외부 라이브러리는 대상에서 제외했다.
- `CGameLogic::HandlePacket`에서 Game/World 요청을 분리하고 이동 목표 검증을 `HandleMove`로 옮겼다.
- `CIocpServer::Run`에서 세션별 완료 처리를 `HandleSessionCompletion`으로 분리했다. 기존 세션 잠금 범위와 I/O 수명을 유지한다.
- `sendQueue`, `pendingSendBytes`, `recvBuffer`, `sendOffset` 등 이름과 한글 주석을 정리했다. 큐 제한값은 기존 2048/32/128을 이름 있는 상수로 표현했다.
- `Packet.h`는 주석·공백을 제외한 코드 토큰이 작업 전 사본과 동일하다. 패킷 번호, 프레이밍, 메시지 스키마 변경을 포함하지 않는다.

## 빌드·기능 확인

`regression.json`의 14개 항목이 모두 종료 코드 0이다. 최초 빌드·자기 점검을 포함한 회귀 12개와 최종 Debug/Release 재빌드·자기 점검 2개다.

| 확인 | 결과 |
|---|---|
| Debug/Release 빌드, 기본 환경, 전투 계산, 공간 검색 | 통과 |
| IOCP/WSAPoll 수신·송신·프레임 오류 경로 | 통과 |
| 전투 쓰레드(워커) 1/2/4, 직렬/병렬 결과 대조 | 통과 |
| 계정·World 이동·스킬·전투·정원·자동 전투 | 통과 |
| 서버 간 채팅·복구·Redis 장애/복구·최종 SQL 저장 | 통과 |
| 리플레이 기록·검증 | 통과 |
| IOCP 풀 OFF / ON / 용량 16 고갈 | 모두 통과; pending_io=0, pool_in_use=0 |

최종 증분 빌드 중 `NetworkWorker.obj`의 LNK1163이 발생해 전체 Rebuild로 중간 파일을 재생성했다. 두 설정의 전체 빌드와 자기 점검은 통과했다. 외부 Protobuf/Abseil 경고는 남아 있다. 빌드 후 추가 코드 수정은 파일명 안내 등 주석 교정뿐이다.

시험은 로컬 MSSQL `127.0.0.1 / project_db`의 시험 데이터와 로컬 Redis를 사용했다. 새 성능 벤치마크나 1,500명 시연은 수행하지 않았다. PDF의 성능 표는 측정 날짜와 함께 기존 기록을 보존한다.

## PDF 확인

학습용 5종 135쪽, A 포트폴리오 36쪽, A 경력기술서 21쪽: 총 7종 192쪽.
전체 페이지의 텍스트·페이지 경계와 렌더링을 검사하고 연락판 및 주요 변경 페이지를 시각 검수했다. 현재 소스 해시, 함수 위치, 코드 발췌를 재생성했다.

- `code-validation.json`: 변경 소스 및 최종 실행 파일 해시, 패킷 코드 대조
- `regression.json`, 각 로그: 실행 결과
- `iocp-fault.json`: 종료 후 I/O·풀 반환 상태
- `pdf-validation.json`: 최종 PDF 해시와 페이지별 검수 결과
- `publication.json`: A 폴더와 스킬 반영 결과

작업 전부터 있던 미커밋 변경은 유지했다. 커밋·푸시는 하지 않았다.
